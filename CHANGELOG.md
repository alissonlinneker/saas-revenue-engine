## [1.0.0] - 2026-09-30

### Added

- `saas-revenue-engine` skill with `SKILL.md` entry point and advise, audit, and implement modes.
- `AUDIT.md` protocol to audit a SaaS project end to end and write a scored report.
- `IMPLEMENT.md` protocol to implement missing revenue capabilities.
- Twelve reference files covering customer lifecycle, metrics, pricing and packaging, go-to-market motions, demand and acquisition, sales process, onboarding and activation, retention and expansion, data and instrumentation, revenue operations, growth stages, and continuous improvement, each with an audit checklist.
- Cheatsheet and glossary.
- Templates: metrics dictionary, tracking plan, audit report, and PostgreSQL reference schema and queries.
- Repository validator (`scripts/validate.py`) and CI workflow with markdownlint.
- README in English and Brazilian Portuguese, contributing guide, code of conduct, security policy, and issue and pull request templates.
